# Requirements

## v1 Requirements

### Core (CORE)
- [ ] **CORE-01**: Usuário pode registrar um novo teste de funil (nome, variação A, variação B, tempo de teste).
- [ ] **CORE-02**: Sistema armazena os dados no Supabase.
- [ ] **CORE-03**: Aplicação usa o tema especificado Shadcn (cmlh0x713000104jrgmds6vcd).

### Dashboard (DASH)
- [ ] **DASH-01**: Dashboard exibe Faturamento Líquido, Vendas Pendentes, Margem e Lucro.
- [ ] **DASH-02**: Dashboard exibe CPA, Gastos com anúncios, ROAS e ROI.
- [ ] **DASH-03**: Dashboard exibe ARPU, Taxa de Aprovação (Cartão, Pix, Boleto), Imposto total, Reembolso e Chargeback.
- [ ] **DASH-04**: Interface com gráfico de Vendas por Horário.

### Funnel (FUN)
- [ ] **FUN-01**: Dashboard exibe o Funil de Conversão (Cliques, Vis. Página, ICs, Vendas Iniciais, Vendas Apr.) e suas porcentagens de queda.

## Out of Scope
- [ ] Automação de extração de dados diretamente do Meta Ads.
